# Customer Churn — Responsible ML Assignment

This repository contains the four requested deliverables for the **ML Problem Framing & Responsible Data Card** task.

## Files
- `problem-framing.md` — ML problem-framing memo
- `responsible-data-card.md` — completed responsible data card
- `baseline.ipynb` — baseline analysis and model notebook
- `risk-register.md` — risk register
- `customer-churn-training-data.csv` — dataset transcribed from the supplied spreadsheet screenshot

## Important limitation
The supplied dataset contains only 12 observations. Any model metrics are illustrative and should not be treated as evidence of production performance.

## Suggested public submission
Upload this folder to a public GitHub repository (if GitHub is accepted by the academy), then submit the repository URL in the academy portal.

## Reproducibility
Run `baseline.ipynb` from top to bottom. It uses the included CSV.
